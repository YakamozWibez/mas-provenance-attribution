# Provenance and attribution in LLM multi-agent systems

**Question.** At equal task and budget, what happens when the agents of an LLM multi-agent system are forced to use structured messages and to declare their sources?

1. How much does error attribution improve, and for which kind of error?
2. How does task performance change?

Author: Emme, Independent Scholar, Italy. Exploratory work in progress.

## Status

| Step | Outcome |
|---|---|
| Pilot 1 (50 GSM8K) | STOP on criteria 4 and 5 |
| Pilot 2 (50 new GSM8K) | STOP on criterion 1 (ceiling, $P_{\text{base}} = 0.92$) |
| LLM judge on pilot 2 | sources do not help a competent attributor; the benefit seen with the deterministic rule was an artefact |
| Pre-registration 02 | test of the theorem's prediction (non-injective case): `prereg/02_non_injective.md`, committed before the run |
| Pre-registration 02 result | sources help when words are stripped: +0.355 [+0.161, +0.548] |
| Pre-registration 03 result (100 new problems) | replicated (+0.196); ambiguity $k$ identifies hard cases (confirmed); $k$ predicting the size of the effect: inconclusive |

Results: [`docs/pilot2_result.md`](docs/pilot2_result.md) (pilots 1–2) and [`docs/results_prereg02_03.md`](docs/results_prereg02_03.md) (pre-registrations 02–03).

## Reproduce

```
cd code
python3 -m venv .venv && source .venv/bin/activate && pip install openai
python tests.py                                   # tests with mock models, free
export OPENAI_BASE_URL=https://api.together.xyz/v1
read -s OPENAI_API_KEY && export OPENAI_API_KEY   # never put the key in a file
python run_pilot.py --family math --data gsm8k:data/gsm8k_test.jsonl --llm openai --model Qwen/Qwen3.5-9B
python judge.py --results results/math_gsm8k_Qwen-Qwen3.5-9B.jsonl --data gsm8k:data/gsm8k_test.jsonl \
                --model openai/gpt-oss-120b --price-in 0.2 --price-out 0.8 --max-tokens 4000
```

Pilot 1 was run with an earlier version of the code (v4). Its rescored numbers come from `code/rescore.py` (v6).
